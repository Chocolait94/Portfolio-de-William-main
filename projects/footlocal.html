FootLocal

Application de gestion de clubs de football locaux avec suivi des matchs.

TypeApplication web & mobile
RôleDéveloppement back-end
FocusEspace administrateur et comptes utilisateurs
ÉtatEn cours

Ce que j'ai réalisé

  • Développement de la partie back-end dédiée à la gestion des fonctionnalités clés.
  • Création de l'espace administrateur pour gérer les matchs (ajout et suppression).
  • Mise en place de la gestion des utilisateurs côté web, avec suppression de comptes par l'administrateur.
  • Développement côté mobile de la création de compte, du login et de la suppression de compte.
  • Ajout d'un motif obligatoire lors de la demande de suppression de compte utilisateur.

Technologies utilisées

  • REST API
  • Gestion d'authentification (JWT)
  • Expo go pour l'application mobile
  • Symfony API
  • React
  • Docker pour la base de donnée avec MySQL
