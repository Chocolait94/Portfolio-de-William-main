Application Météo

Web app de prévisions météo en temps réel selon la ville recherchée.

TypeApplication web API
RôleFront-end JavaScript
ObjectifDonnées en temps réel
ÉtatEn ligne
temps de réalisation3 jours

Ce que j'ai réalisé

  • Appel à une API OpenWeather avec gestion des réponses et des erreurs.
  • Création d'une interface claire pour afficher température, humidité et vent.
  • Mise en place d'une recherche de ville simple et rapide.
  • Optimisation de l'affichage sur mobile et sur grand écran.

Technologies utilisées

  • HTML5
  • CSS3
  • JavaScript
  • REST API
